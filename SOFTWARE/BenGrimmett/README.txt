HXVIEW22.PR (HEXVIEW.V22)
MENU.PI (menu.bin)
Tandy WP-2 / WP-3 files for Brians flash cards
HXVIEW22.PR fixes a bug where if you returned back to the OS after messing with ROM banking it would crash. This is now fixed
MENU.PI is the flash cart multi menu including MSbasic, hexview and a small space invaders game. There's still heaps of room to add your own applications to the menu.
To flash MENU.PI, first start TPDD and send hexview to the WP. If you already have Hexview on your WP, skip this step. 
Run Hexview and press S for serial mode. 
Run RomCardWriter to flash MENU.PI to your flash cart. This will take around 1-2minutes.
To run the program on your flash card, you need to press F2 + 7 but this will only work when you're in the word processor.
'MONITOR' will quit out of MSbasic. F2 & Del will return to the OS from the menu.
